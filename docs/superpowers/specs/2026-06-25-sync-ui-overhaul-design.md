# Sync UI Overhaul Design

> 日期：2026-06-25 | 状态：待审核

## 目标

优化条目同步视图（`buildSyncView()`）的逻辑和表现，提升对比效率和可用性。

## 非目标

- 不改动后端 API（compare / sync 端点不变）
- 不改动收藏/日历视图
- 不新增平台（MAL 已预埋，本次不实现）

---

## 一、Token 持久化

- 对比成功后，token 存入 `sessionStorage`，key：`sync-tokenA` / `sync-tokenB`
- 页面加载时自动从 sessionStorage 恢复已填 token
- 成功验证后显示 "✓ username (bgm.tv) 已验证"，可点清除
- 切换页面、刷新后 token 保留（同浏览器会话）
- 关闭标签页后 token 自动清除

## 二、卡片布局

每张对比卡片结构：

```
┌─────────────────────────────────────┐
│ 咒术回战                 24话/10分  │ ← 标题 + 总话数/评分（取较高者）
├──────────────────┬──────────────────┤
│   Account A      │   Account B      │
│ [看过] badge     │ [看过] badge     │ ← 彩色状态 badge
│ ████████░░ 24话  │ ██████░░░░ 20话  │ ← 进度条
│ ★ 10分          │ ★ 8分 ↑ 4       │ ← 评分，差 2 分以上显示差值
└──────────────────┴──────────────────┘
│              ☑ 同步此项              │ ← 居中 checkbox
└─────────────────────────────────────┘
```

**颜色规则：**

| 条件 | 左边框色 |
|------|---------|
| 状态不同 | 红 `#e94560` |
| 状态相同但进度不同 | 橙 `#ff9800` |
| 仅 A 有 | A 侧绿色 `#4caf50`，B 侧灰 `—` |
| 仅 B 有 | B 侧绿色，A 侧灰 `—` |
| 完全相同 | 边框无颜色，默认折叠 |

**Badge 配色（WatchStatus → 颜色）：**

| 状态 | 颜色 |
|------|------|
| watching | 蓝 `#00a1d6` |
| completed | 绿 `#4caf50` |
| plan_to_watch | 紫 `#9b59b6` |
| on_hold | 黄 `#f39c12` |
| dropped | 红 `#e74c3c` |

## 三、顶部导航栏

**统计 pill 行（可点击筛选）：**
```
[全部 286] [差异 15] [仅A 3] [仅B 5] [相同 268]
```

点击 pill 即切换筛选，当前选中 pill 高亮。

**工具栏：**
```
[全选] [反选] [20/页 ▼] [搜索框]          [Account A → Account B ▼] [完整同步] [选中同步]
```

- 搜索框：实时过滤卡片标题（前端 `filter`，无需请求）
- 方向选择器 + 完整同步 + 选中同步 在最右侧

## 四、卡片流实现

- 所有卡片渲染为 `<div>` 流式排列（`display:flex;flex-direction:column;gap`）
- 分页控制每次显示 N 张，超出部分隐藏
- 分页逻辑复用现有的 ellipsis 逻辑
- 相同条目默认 `display:none`，点击统计 pill 的 "相同" 时展示并展开

## 五、Token 区域

- 成功验证后替换输入框为 "'✓ username (bgm.tv) 已验证' + [清除按钮]"
- 清除后恢复输入框
- 加载时读取 sessionStorage，有则预填并标记为 "上次输入"（需重新点对比验证）

## 六、不变部分

- 后端 API 端点不变
- `PlatformClient` 接口不变
- `compareAccounts` / `executeSync` 签名不变
- 收藏/日历视图不变
